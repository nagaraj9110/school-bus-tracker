# 🚌 School Bus Tracker – Real-Time GPS Tracking System

A smart and user-friendly School Bus Tracking System that allows parents and students to track school buses in real time using GPS technology.

The system allows drivers to share their live location while students and parents can view the bus location through a web application.

## 🌐 Live Demo

**Website:** https://school-bus-tracker-delta.vercel.app/

**GitHub Repository:** https://github.com/nagaraj9110/school-bus-tracker

## ✨ Key Features

- 🚌 Driver Dashboard
- 📍 Real-time GPS Location Sharing
- 👨‍👩‍👧 Student and Parent Tracking
- 🗺️ Live Bus Location Tracking
- ⚡ Real-time communication using Socket.IO
- 📱 User-friendly interface
- 🔄 Automatic location updates
- 🔒 Live location is handled through a real-time connection

## ⚙️ How to Run Locally

**Step 1: Clone the repository**

```bash
git clone https://github.com/nagaraj9110/school-bus-tracker.git
```

**Step 2: Open the project folder**

```bash
cd school-bus-tracker
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the server**

```bash
npm start
```

**Step 5: Open in browser**

```text
http://localhost:3000
```

## 🔄 How It Works

1. The driver opens the Driver Dashboard.
2. The driver registers the bus.
3. GPS location is shared through the application.
4. Parents and students open the tracking page.
5. The bus location is updated in real time.

## 🎯 Project Objective

The main objective of this project is to improve school transportation safety, provide real-time bus location information, and help parents and students know where their school bus is.
